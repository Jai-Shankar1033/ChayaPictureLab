## Transitive dependencies

The packages above may install additional dependencies. Their own copyright notices and licence terms continue to apply. When redistributing a built or bundled application, inspect the licences and notices for the complete dependency set—not only the direct dependencies listed here.

The project repository should contain source files and project assets, not a local virtual environment. Do not commit `.venv/`, package caches, or installed third-party package files. If you intentionally distribute a bundled environment or binary package, include all licence and notice files required by the included software.
